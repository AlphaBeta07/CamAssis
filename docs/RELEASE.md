# CamAssis Release Engineering & App Store Submission Guide

## 1. Application Identifiers

- **App Name**: CamAssis
- **Package Name (Android)**: `com.camassis.app`
- **Bundle Identifier (iOS)**: `com.camassis.app`
- **Version**: `1.0.0`
- **Version Code (Android)**: `1`
- **Build Number (iOS)**: `1`

## 2. EAS Build Profiles (`eas.json`)

```bash
# Install EAS CLI
npm install -g eas-cli

# Login to Expo
eas login

# Configure project
eas project:init
```

### Build Commands:
- **Android APK (Internal Testing)**:
  ```bash
  eas build --platform android --profile preview
  ```
- **Android AAB (Google Play Store Production)**:
  ```bash
  eas build --platform android --profile production
  ```
- **iOS Simulator Build**:
  ```bash
  eas build --platform ios --profile preview
  ```
- **iOS Production Build (TestFlight / App Store)**:
  ```bash
  eas build --platform ios --profile production
  ```

## 3. Google Play Store Submission Checklist

1. **Google Play Console Account**: Created and verified ($25 fee).
2. **App Integrity / Signing**:
   - Let Google Play manage app signing keys (Play App Signing).
   - Upload keystore generated by EAS or your secure upload key.
3. **Target SDK**:
   - Minimum: Android 7.0 (API 24)
   - Target: Android 15 (API 35)
4. **Permissions Declaration**:
   - `android.permission.CAMERA`: Used exclusively for camera preview and pose overlay guidance.
   - `android.permission.READ_MEDIA_IMAGES` / `WRITE_EXTERNAL_STORAGE`: Used to save captured photos directly to device gallery and select custom pose reference images.
5. **Data Safety Section**:
   - **Photos & Videos**: Not collected on servers. Stored only locally on device.
   - **Personal Info**: Email and Full Name collected only for registered accounts for authentication and sync. No personal data shared with third parties.
   - **Data Deletion**: Users can request full account deletion inside the app.

---

## 4. Apple App Store Submission Checklist

1. **Apple Developer Program Account**: Enrolled ($99/yr).
2. **Bundle ID & Capabilities**:
   - Register App ID `com.camassis.app` in developer.apple.com.
3. **Info.plist Privacy Strings**:
   - `NSCameraUsageDescription`: *"CamAssis needs camera access to provide transparent pose guidance and real-time pose coaching."*
   - `NSPhotoLibraryUsageDescription`: *"CamAssis needs photo library access to automatically save your captured photos to your Photos app and select pose reference pictures."*
   - `NSPhotoLibraryAddUsageDescription`: *"CamAssis automatically saves your photos directly to your Photos library."*
4. **App Privacy Nutrition Label**:
   - **Data Not Linked to You**: None.
   - **Data Linked to You**: User ID, Email (Authentication only).
   - **Data Used to Track You**: None.
5. **Account Deletion (Guideline 5.1.1(v))**:
   - Located in **Profile -> Delete Account**.
   - Verified functional with double-confirmation dialog.
